# Revive Shop

Інтернет-магазин косметики центру естетичної медицини Revive (`shop.reviveclinic.com.ua`).

## Стек

| Шар | Рішення | Чому |
|---|---|---|
| CMS / адмінка | **WordPress 6.8+** | Основний сайт клініки вже на WordPress — команда знає адмінку |
| Магазин | **WooCommerce 9.x** | Каталог, кошик, checkout, замовлення, склад, промокоди «з коробки» |
| Тема | **Revive Shop** — власна блочна тема (FSE) | Цей репозиторій. Стилі в `theme.json`, без збірки та npm |
| Оплата | LiqPay / WayForPay / monobank acquiring (плагін) | Українські еквайри; Stripe і Shopify Payments для UA-мерчантів недоступні |
| Доставка | Нова пошта (плагін: Morkva / «Nova Poshta для WooCommerce») + Самовивіз (вбудований Local pickup) | Автозаповнення міст/відділень, створення ТТН з адмінки |
| Фіскалізація | Checkbox (плагін) або каса Beauty Pro | Уточнити з бухгалтером клініки, що вже налаштовано |
| CRM | **Beauty Pro API** → власний плагін `revive-beautypro` (наступний етап) | Потрібен тариф Ultimate і погодження інтеграції з Beauty Pro |
| Хостинг | Український VPS або керований WP-хостинг, PHP 8.3, MariaDB, HTTPS | Піддомен `shop.` окремим сайтом |

## Структура

```
docker-compose.yml        локальне середовище (WordPress + MariaDB + WP-CLI)
bin/setup.sh              встановлення WP українською, WooCommerce, демо-товари
wp-content/themes/revive-shop/
  theme.json              кольори, шрифти, відступи, стилі кнопок
  style.css               заголовок теми + те, що не вміє theme.json
  functions.php           підключення стилів, шрифтів, підтримка WooCommerce, контакти клініки
  templates/front-page.html   лендінг (головна магазину)
  parts/header.html, footer.html
  patterns/               секції лендінгу — редагуються в Site Editor
  assets/fonts/           Montserrat + Commissioner (локально, з кирилицею)
  assets/img/             тимчасове зображення для банера
```

Секції лендінгу (`patterns/`): банер → категорії → «Рекомендують наші лікарі» (рекомендовані товари WooCommerce) → запис на консультацію → доставка та оплата.

## Локальний запуск

Потрібен Docker Desktop.

```bash
docker compose up -d
docker compose run --rm cli bash /bin-revive/setup.sh
```

Відкрийте http://localhost:8080 — адмінка: http://localhost:8080/wp-admin.
Логін і пароль для локальної розробки задані на початку `bin/setup.sh` (змінні `ADMIN_USER` / `ADMIN_PASS`).

Без Docker: встановіть [LocalWP](https://localwp.com/), створіть сайт, скопіюйте папку теми в `wp-content/themes/`, встановіть WooCommerce і активуйте тему **Revive Shop**.

## Бренд

- Кольори взято з reviveclinic.com.ua: фон `#181A1B`, текст `#EAE9E6`, зелений `#577B50`, кнопки-«пігулки» з радіусом 44px.
- Заголовки на основному сайті — **DIN Pro** (платний шрифт). Тема спершу шукає `DIN Pro`, якщо його немає — використовує безкоштовний **Commissioner** (OFL, підтримує кирилицю). Якщо в клініки є веб-ліцензія DIN Pro, додайте файли в `assets/fonts/` і пропишіть їх у `theme.json`.
- Логотип: зараз текстовий напис «REVIVE». Справжній логотип можна додати через блок «Логотип сайту» в шапці (Вигляд → Редактор).

## Що далі

1. Реальний каталог: фото, склад (INCI), описи, бренди.
2. Плагіни оплати, Нової пошти та фіскалізації; налаштувати поріг безкоштовної доставки (зараз 2 000 ₴, фільтр `revive_shop_free_shipping_from`).
3. Шаблони товару, каталогу, кошика і checkout — зараз використовуються стандартні шаблони WooCommerce зі стилями теми.
4. Сторінки: доставка та оплата, повернення, публічна оферта, політика конфіденційності.
5. Інтеграція з Beauty Pro: клієнти, продажі, синхронізація залишків.
